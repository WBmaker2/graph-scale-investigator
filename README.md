# 그래프 눈금 수사대

> 같은 자료를 다른 축으로 그리면 판단이 어떻게 달라지는지 수사하는 초등 5~6학년 수학·미디어 문해 활동

🔗 **데모**: https://wbmaker2.github.io/graph-scale-investigator/

## 소개

`그래프 눈금 수사대`는 학생이 그래프의 모양만 보고 결론을 내리지 않고, 실제 숫자와 축 설정(시작점·눈금 간격·단위)을 함께 확인하는 한 차시 활동을 지원합니다. 자료를 수집하거나 그래프를 그리는 앱이 아니라, **이미 주어진 동일 자료가 표현 방식 때문에 다르게 보일 때 그 차이를 수사**하는 데 집중합니다.

## 학습 목표

- 그래프의 제목·가로축·세로축·단위·눈금 간격을 찾아 말하기
- 막대 높이·선의 기울기와 실제 수치 차이를 분리해 확인하기
- 시작점·눈금 간격·단위·축 범위가 바뀌면 시각적 인상이 어떻게 달라지는지 설명하기
- 목적에 맞는 공정한 그래프 표현을 선택하고 이유 쓰기

## 미션 구성

| 미션 | 자료 | 핵심 개념 |
|---|---|---|
| 훈련소 | 정직 vs 과장 막대 | 그래프 읽기 절차 |
| 사건 1. 잘린 축 | 재활용 병 48·50·52·54 | 시작점과 실제 차이 분리 |
| 사건 2. 눈금 한 칸 실종 | 우유팩 0·10·20·30 | 눈금 간격과 단위 해석 |
| 사건 3. 단위 바꾸기 | 운동장 120·150·180 m | 단위 vs 실제 양 |
| 사건 4. 선의 기울기 착시 | 도서 대출 40·42·44·46 | 기울기 vs 증가량 |
| 사건 5. 목적에 맞는 그래프 | 급식 선호도 12·15·16·17 | 목적별 표현 선택 |

## 기술 스택

- **Vite + React 18 + TypeScript**
- 차트는 **순수 SVG 직접 렌더링** (축 100% 명시적 제어 — 자동 스케일링 방지)
- 스타일은 단일 CSS 파일
- 테스트는 **Vitest** (61개: 단위 + 콘텐츠 + UI 흐름)

## 실행

```bash
bun install        # 의존성 설치
bun run dev        # 개발 서버 (http://localhost:5173)
bun run test       # 61개 테스트 실행
bun run build      # 프로덕션 빌드 → dist/
bun run preview    # 빌드 결과 미리보기
bun run deploy     # 빌드 + gh-pages 배포
```

> `npm`이나 `pnpm`으로 대체 가능합니다.

## 구조

```
src/
  data/            # 미션 데이터 + 피드백 규칙
  features/graph-investigator/   # React 컴포넌트
  lib/             # 축 계산·검증 순수 함수 (테스트 대상)
  styles/          # 단일 CSS
test/              # Vitest 단위/콘텐츠/UI 테스트
```

## 설계 원칙

- **축을 데이터로** — 그래프 변형은 값 배열이 아니라 `AxisConfig`만 바꿔 만든다
- **계산·판정은 순수 함수** — `lib/`에 두어 단위 테스트 가능
- **색상 비의존** — 정직/주의 그래프를 색이 아닌 텍스처(사선/점)·라벨·수치로 구분
- **모션 줄이기 존중** — `prefers-reduced-motion` 미디어쿼리
- **"0이 아니면 무조건 틀림" 오개념 방지** — 막대는 0 시작 권장, 선그래프는 목적별 허용
